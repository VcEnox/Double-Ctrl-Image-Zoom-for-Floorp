# Double Ctrl Image Zoom for Floorp 
Microsoft Edge Style Double-Ctrl Image Zoom for Floorp

I switched from Microsoft Edge to Floorp. I couldn’t find the feature in Floorp that allows zooming in on images by pressing CTRL twice. I used this feature all the time in Edge, so I wrote a userscript. I don’t know whether it will work on other Firefox forks. I also don’t know if it works with any other user script manager besides Tampermonkey.
